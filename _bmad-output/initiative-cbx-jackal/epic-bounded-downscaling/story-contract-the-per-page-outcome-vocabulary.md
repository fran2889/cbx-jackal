# Contract: the per-page outcome vocabulary

## Description

Fixes the per-page states including downscaled and spread-exempt, the rule that not converted keeps exactly one meaning, and how reversibility is stated per page and in the run-level mode line. Records the ruling in this epic's envelope.

## Acceptance Criteria

Verify: The vocabulary is written down, including what a downscaled page is called and the exact wording for both the per-page line and the run-level mode line.
